# Database Schema

## User Model (`expenses.User`)
* `id` (AutoField, PK)
* `username` (CharField, Unique)
* `role` (CharField: ADMIN, APPROVER, EMPLOYEE)

## ExpenseReport Model (`expenses.ExpenseReport`)
* `id` (AutoField, PK)
* `owner` (ForeignKey -> User)
* `title` (CharField)
* `start_date` (DateField)
* `end_date` (DateField)
* `status` (CharField: DRAFT, SUBMITTED, APPROVED, REJECTED, PAID)
* `is_archived` (BooleanField, default=False)
* `rejection_reason` (TextField, nullable)
* `assigned_approvers` (ManyToManyField -> User)
* `created_at` (DateTimeField)

## ExpenseLine Model (`expenses.ExpenseLine`)
* `id` (AutoField, PK)
* `report` (ForeignKey -> ExpenseReport)
* `date` (DateField)
* `category` (CharField: Travel, Meals, Supplies, Other)
* `amount` (DecimalField)
* `description` (CharField)
* `receipt` (FileField, upload_to='receipts/', nullable)

## ReportHistory Model (`expenses.ReportHistory`)
* `id` (AutoField, PK)
* `report` (ForeignKey -> ExpenseReport)
* `changed_by` (ForeignKey -> User)
* `old_status` (CharField)
* `new_status` (CharField)
* `comment` (TextField, nullable)
* `timestamp` (DateTimeField)
